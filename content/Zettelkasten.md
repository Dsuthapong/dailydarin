A Personal Knowledge Management system that was invented by  

### Key principles
- Notes are atomic: one note one ide
- Notes are standardized format
	- Separate YOUR understanding from external sources (but closely link them together)
- Write to think
	- Information is organized with “keywords” ==to help you THINK== not to help you FIND stuff
- Always connecting (and reuse)
- Write in your own words, with great care

### How it works
- One slip box for the reference system with the bibliographic information. The other one is the main box with the ideas and insights
	-  When reading, he has an index card at hand to write down things he didn’t want to forget, and on the back of the card he wrote down bibliographic information such as page number 
- Review the notes and write down insights on the another index card and store in the main slip box
- Most related cards are stored close together
### Process
1. Read interesting things
2. Write about it. Tag with keywords.
3. Come up with questions 
4. Read more
5. Write more
6. Finally publish it 
### Notes types
**Index**
Stores keywords that gives the context to notes. Each index links to 1-2 notes.

**Permanent notes**
Your unique insights from internalizing external information, whether it is media consumption or life experience

**Literature notes** 
Summarization of understanding from consumed external media

**Fleeting notes**
Notes taking when anything comes to your mind. Designed to be processed within 1-2 days.
