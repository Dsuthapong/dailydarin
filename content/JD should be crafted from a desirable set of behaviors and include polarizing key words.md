---
title: JD should be crafted from a desirable set of behaviors and include polarizing key words
---
#permanent 

Besides technical skills and experiences, a JD should has a portion designed to target a set of behaviors we want. 

To create JD, we should: 
1. Create a set of behaviors we want in the candidate
2. Create a set of behaviors we DON'T want 

And then
- Include desirable behaviors in the JD with polarizing keywords
	- For example, if we want people with high achiever, we include things like:
		- "You are a self-driven person. You don't settle for less and can't stand mediocrity. You always deliver the best results and make sure your work is done on time, at the highest quality."
		- "You love numbers. Solving problems is your snack. You believe that detail analysis will solve all major problems in the business"
- Has a note that list non-desirable keywords
