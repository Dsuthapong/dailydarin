## Delegation is all about co-creating with another person 
- Pro: 
	- Done right, you can achieve more than you can do on your own!
		- More time
		- More Expertise
	- For manager,s this could be a development tool
- Cons: 
	- Needs communication (overhead)
	- Lost of control

## Should you delegate?
#### Do yourself
- For Work
	- [x] Only you can do it (CEO's jobs)
	- [x] The company needs you to do it 
		- [x] You are really good 
		- [x] Speed of doing this is important 
		- [x] Important 
		- [x] The money saved for not hiring is better used somewhere 
- Personal 
	- [x] Only you can do it (Life choice)
	- [x] You enjoy doing it
	- [x] You really want it specific way that is very hard to communicate 
	- [x] Having other people doing it really disturbs you 
#### Delegate 
- You should delegate the rest
